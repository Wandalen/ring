# Seq

## Representation

A publication's ordinal in a ring's whole history, counting from zero — a public
`u64` newtype with no invariant. Every `u64` is a valid `Seq`, which is why the
field is `pub` and `Default` is derived, and why this type has no `type/`
instance: there is nothing to validate.

**Its guarantee is not enforced, it is argued.** The type doc claims monotonicity
and non-wrapping on the grounds that a `u64` at 10⁹ publications per second runs
for roughly 584 years, and the whole family depends on that — `Seq` comparison is
plain `<`, with no lap-aware wrap-around logic anywhere. Nothing in the type
prevents a caller writing `Seq( u64::MAX )`; the argument is that no reachable
workload gets there. The wrapping counterpart is
[`SlotIndex`](003_slot_index.md), which is a separate type for exactly this
reason (→ [`../../data_structure/001`](../../data_structure/001_two_position_types_and_the_fold_between_them.md)).

It is the most widely used item in the crate. Eighteen of the thirty-two sibling
crates name it in `src/`, twenty in `tests/`, and its
[`ZERO`](../associated_constant/001_seq_zero.md) constant alone is matched on 59
`src/` lines across eleven of them.

**That 59 is a documentation figure, not a usage figure**, and the distinction is
the one this catalog is required to draw
(→ [`../readme.md`](../readme.md) § Where the counts come from). Filtering doc
comments out leaves **six** production references, in two crates:

```sh
cd "$(git rev-parse --show-toplevel)"
command grep -rn 'Seq::ZERO' ring_*/src | command grep -v '^ring_types/' \
  | command grep -vc ':[0-9]*: *//'                                              # 6
```

Live output:

```
6
```

All six are initialisation — two `Default` impls in `ring_atomic`, four field
initialisers in `ring_cursor::…::new` — and not one is a comparison
(→ [`../associated_constant/001_seq_zero.md`](../associated_constant/001_seq_zero.md)).

## Definition

`ring_types/src/id.rs:25`

```rust
#[ derive( Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash, Default ) ]
pub struct Seq( pub u64 );
```

Nine derives. `PartialOrd`/`Ord` are load-bearing rather than conventional — the
family's gating comparisons are `<` on this type, so deriving the ordering *is*
the ordering contract.

crates work in sequence space and never see a slot at all, and that separation is
what the two-type split bought.
