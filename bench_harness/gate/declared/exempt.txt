# Crates deliberately not graded by any family, one per line, `crate_name  reason`.
#
# G18 reads this file and counts its entries out loud on every run, reached or
# not. That is the point: an exemption is the one way to reach G18 without
# gating anything, so a family that reached by emptying itself into this file
# reads differently from one that reached by declaring its crates. A bare name
# with no reason is not an exemption. G18 reports it as `exemption without a
# reason` and does not reach.
#
# There are no entries below, and the `ring` family has never had one: every
# crate in this repository has always been declared in `ring/crates.txt`
# rather than excused from it.
#
# This header exists for G22's own non-vacuity floor. Every check G22 makes is a
# negative. An entry passes by *not* looking implemented, so an empty file gives
# a broken detector nothing to be broken against. `g22_exemption_expiry.sh`
# treats a file this small as more likely a wrong `$GATE_EXEMPT` path or a
# truncated read than a curated empty list. Raw byte count tells the two apart,
# and that is the whole reason this header is long enough to clear that floor
# rather than short enough to state its own purpose and stop.
#
# Adding a line here is a decision to stop grading a crate. It follows the same
# `crate_name  reason` form as every other entry this family will ever add.
