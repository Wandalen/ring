# The doc-corpus standard G14-G17 grade a family against. The ring family no
# longer declares those gates or carries the corpus; this file stays so the
# gates can still be run by name.
#
# Declared here rather than hard-coded in the gates for the same reason crate
# membership moved out of a glob. A threshold living in the script that
# checks it cannot be changed without editing the checker, so the standard and
# the instrument are one artifact and neither can contradict the other visibly.
# Raising `min_findings` below by one must flip every crate at the floor to NOT
# REACHED. If it does not, a gate is reading its own constant.
#
# Format: `key value`, one per line, comments and blanks stripped by decl_lines.

# ---- the thirteen doc definitions every crate carries ----------------------
#
# `definition/` is deliberately absent from this list and present in the tree.
# It holds the Module Index, which is apparatus describing the other thirteen
# rather than a fourteenth dimension of design. G14 requires all thirteen plus
# `definition/`, which is why the count it reports is 13 and the directory count
# it accepts is 14.

definition algorithm
definition api
definition data_structure
definition decisions
definition integration
definition invariant
definition item
definition lifecycle
definition non_functional_requirement
definition pattern
definition pitfall
definition type
definition workaround

# ---- minimum counts, per crate ---------------------------------------------
#
# Floors, not targets. A gate that treated these as equalities would report the
# most complete crates in the family as violations.

min_definitions 13
min_instances 26
min_findings 52

# ---- the closed tier vocabulary --------------------------------------------
#
# Reachable tiers are bolded in the source and record tiers are not. The bolding
# matters, because it is how a reader scanning a findings table tells something
# that can still be acted on from something recorded for the archive. A hybrid
# such as `n/a — latent hazard` says both at once, and G17 exists to refuse it.
#
# This list was taken from the corpus rather than composed for it. A tier
# declared here that nothing uses would be a bar the family never set; a tier
# used that is not declared here fails crates for the instrument's mistake
# rather than the corpus'.
