### The Shape Every Definition Found

Stated once because most of the thirteen definitions reach it independently:
**almost everything this crate is careful about is unreachable in a shipping
build.** The code is correct throughout — every mapping total, every predicate
right, every test passing. What the corpus keeps finding is that the care has no
route to a caller.

Not one is a bug in the sense of a failing test. The 237 lines do exactly what

configuration can construct, which is simultaneously the sole value making
`accepted_incoming()` true (OV30) and the sole witness keeping the crate's
central safety test non-vacuous (OV24).
