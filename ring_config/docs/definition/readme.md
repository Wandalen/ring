### The Shape Every Definition Found

Stated once because most of the thirteen definitions reach it independently:
**every decision this crate makes carefully guards a path with no traffic.** The
code is correct throughout — the two ranges hold, the setters commute, the ten

is that the guard and the traffic are in different places.
